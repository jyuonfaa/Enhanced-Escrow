🛡️ Setup Guide

Enhanced Escrow
Complete Setup Guide

Step-by-step instructions for running the project on a brand new Windows laptop

Frontend React + Vite (Port 3000)
Backend Node.js + Express (Port 5002)
Database Supabase (Online)

What You'll Need Before Starting

  • The project folder (zipped or from USB/Google Drive)
  • A stable internet connection
  • About 15–20 minutes
1
Install Node.js

Node.js is the only software you need to install. It powers both the backend server and the frontend build tool.

  1. Open your browser and go to https://nodejs.org
  2. Click the big green "LTS" button (Long Term Support — the stable version)
  3. Run the downloaded .msi installer
  4. Click Next → Next → Next → Install → Finish (all defaults are fine)
  5. If it asks "Install tools for native modules?" — check that box
VERIFYOpen Command Prompt and run both commands:
node --version
npm --version
You should see version numbers like v20.x.x and 10.x.x. If you do, Node.js is installed correctly.
2
Extract / Place the Project

If you received the project as a .zip file:

  1. Right-click the zip file → Extract All
  2. Choose a simple location like C:\Projects\enhanced-escrow
  3. Open that folder — you should see two sub-folders: backend and frontend
Avoid paths with spaces (e.g. don't use a folder named My Projects). A short path like C:\Projects\enhanced-escrow is best.
3
Open a Terminal in the Project
  1. Press Windows key, type cmd, press Enter
  2. Navigate to the project root by typing:
cd C:\Projects\enhanced-escrow

You should now be inside the folder that contains the backend and frontend folders.

4
Set Up the Backend
4aNavigate to the backend folder
cd backend
4bInstall all backend dependencies
npm install
This downloads all required packages. It may take 1–3 minutes — wait for it to finish.
4cCheck the environment file

The .env file in the backend folder already contains the database connection and secret key. You do not need to change anything — the project connects to the live Supabase database automatically.

To confirm the file exists, run: dir .env — you should see it listed.
4dGenerate the Prisma database client
npx prisma generate
This tells Prisma to build the database access layer based on the schema. Must be done before building.
4eBuild the TypeScript backend
npm run build
This compiles TypeScript to JavaScript. You'll see a dist/ folder appear when complete.
4fStart the backend server
npm run dev
You should see: "Server is running on port 5002" and "Database connected successfully"
Leave this terminal window open. The backend must stay running the entire time.
5
Set Up the Frontend
Open a NEW terminal window — do not close the backend one from Step 4.
5aNavigate to the frontend folder
cd C:\Projects\enhanced-escrow\frontend
5bInstall all frontend dependencies
npm install
This may take 2–5 minutes. Wait for it to complete fully.
5cStart the frontend development server
npm run dev
You should see: "VITE ready — Local: http://localhost:3000/"
6
Open the App in Your Browser
  1. Open Google Chrome or any browser
  2. Go to: http://localhost:3000
  3. You should see the Enhanced Escrow login page ✅

❗ Common Problems & Fixes

Problem Fix
'node' is not recognized Node.js wasn't installed properly. Restart your PC and try again, or reinstall from nodejs.org
npm install fails with permission errors Run Command Prompt as Administrator (right-click → "Run as administrator")
Backend says "port already in use" Another app is using port 5002. Restart your PC or close other apps.
Frontend can't connect to backend Make sure the backend is running in Terminal 1 first before starting the frontend
prisma: command not found Use npx prisma instead of just prisma
Cannot find module './dist/server.js' You skipped Step 4e. Run npm run build first
